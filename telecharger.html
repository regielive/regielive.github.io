Installer sous Windows, pas à pas

  1. Ouvrez le fichier téléchargé.Il se trouve en général dans le dossier « Téléchargements ».
  2. Si Windows affiche « Windows a protégé votre ordinateur »cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ». Ce message apparaît tant que l’installateur n’est pas signé numériquement ; la signature est prévue.
  3. Suivez l’installation.RégieLive s’installe dans les Programmes de Windows, comme un logiciel classique. Restez connecté à Internet : l’installation télécharge NDI, utile pour envoyer l’image par le réseau, s’il n’est pas déjà présent.
  4. Lancez RégieLive et créez votre premier projet.Un projet correspond à un culte et tient dans un seul dossier.
  5. Faites le test de l’ordinateur.Préférences → Tester ce PC : trois minutes pour savoir ce que votre ordinateur peut faire.

Installer sous Ubuntu, pas à pas

  1. Double-cliquez sur le fichier téléchargé.« RegieLive-2.1-Ubuntu.deb », en général dans le dossier « Téléchargements ». Le Centre d’applications d’Ubuntu s’ouvre.
  2. Cliquez sur « Installer ».Ubuntu demande votre mot de passe une fois. Tout ce dont RégieLive a besoin pour lire les vidéos et les sons est installé en même temps : restez connecté à Internet.
  3. Lancez RégieLive depuis les applications.Les fichiers de projet (.rliv) s’ouvrent ensuite par un double-clic dans Fichiers.
  4. À la première ouverture d’un projet, laissez faire la « Préparation des vidéos ».RégieLive prépare une fois pour toutes une version légère de chaque vidéo pour une régie fluide ; un panneau montre l’avancement.
  5. Besoin de NDI ?RégieLive l’installe lui-même, en un clic, la première fois que vous créez une sortie NDI : pas de terminal ni de manipulation.

Les mises à jour

Les nouvelles versions sont publiées sur cette page, avec leurs nouveautés. Depuis la version 1.99, RégieLive vous signale lui-même qu’une nouvelle version existe, avec un lien vers cette page. Il ne le fait jamais pendant un culte, et rien ne s’installe sans vous. Si vous avez une version plus ancienne, installez la dernière version par-dessus : vos projets, chants et réglages sont conservés.

Besoin d’aide ?

Dans RégieLive, la touche F1 ouvre l’aide intégrée. Le manuel et les questions fréquentes répondent aussi à la plupart des questions. Sinon, écrivez-nous.
